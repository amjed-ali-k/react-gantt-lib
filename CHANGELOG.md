# Changelog

All notable changes to this project are documented in this file and in

## [0.1.0](https://github.com/amjed-ali-k/react-gantt-lib/releases/tag/v0.1.0) — 2026-06-22

Initial public release on npm.

### What's Changed

* [Init Repo](https://github.com/amjed-ali-k/react-gantt-lib/commit/3e0df161aaea52ec8ee606e6ae3f7a4a590252ce) ([3e0df16](https://github.com/amjed-ali-k/react-gantt-lib/commit/3e0df161aaea52ec8ee606e6ae3f7a4a590252ce))
* [Add interactive features to GanttChart components](https://github.com/amjed-ali-k/react-gantt-lib/commit/fa3508b904e8d0050623f7b56da8cb35fc2cc4e4) ([fa3508b](https://github.com/amjed-ali-k/react-gantt-lib/commit/fa3508b904e8d0050623f7b56da8cb35fc2cc4e4))
  * Introduced `onGanttClick` and `onGanttContextMenu` callbacks for various elements including tasks, baselines, event markers, and empty timeline areas.
  * Enhanced `GanttChart`, `TimelineHeader`, `TimelineBody`, and other components to support interaction and event emission.
  * Updated styles to reflect interactive states for date markings and timeline elements.
  * Added tests to verify the functionality of new event handlers.
