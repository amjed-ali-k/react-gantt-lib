# Changelog

All notable changes are documented here and on [GitHub Releases](https://github.com/amjed-ali-k/react-gantt-lib/releases).

## [0.1.0](https://github.com/amjed-ali-k/react-gantt-lib/releases/tag/v0.1.0) — 2026-06-22

Initial public release on npm.

### What's Changed

* Init Repo
* Add interactive features to GanttChart components
  * Introduced `onGanttClick` and `onGanttContextMenu` callbacks for tasks, baselines, event markers, and empty timeline areas.
  * Enhanced `GanttChart`, `TimelineHeader`, `TimelineBody`, and other components to support interaction and event emission.
  * Updated styles for interactive date markings and timeline elements.
  * Added tests for new event handlers.
